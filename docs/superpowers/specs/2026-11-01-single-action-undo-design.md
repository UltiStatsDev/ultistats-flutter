# Одношаговая отмена действий матча

Пользователь согласовал один буфер предыдущего состояния. После успешной отмены
буфер очищается; ещё одна отмена возможна только после нового действия.
Истории состояний и последовательного отката нескольких действий нет.

Серверные действия отменяются bodyless POST
`/api/v1/matches/{matchId}/events/undo`. Восстанавливается состояние до действия:
пулл возвращает выбор пуллера, подбор — выбор принимающего, пас — прежнего
владельца диска, гол — прежний счёт и игру. Начало/окончание обеих пауз также
отменяются с восстановлением их исходного timestamp, без отдельного сохранения
длительности. Подтверждение состава/команды для пулла — единственное отменяемое
локальное действие: возврат к составу без запроса на сервер. Редактирование
полей состава не создаёт отдельных шагов отмены.

Общий таймер матча продолжает идти во всех фазах, включая таймаут и халфтайм;
отмена не откатывает его. Счётчики самих пауз остаются отдельными.
Кнопка «Отменить действие» видна в общей рамке всех экранов проведения матча,
под счётом, и использует цвета/типографику темы. Без буфера она неактивна.
Отмена немедленная, без подтверждения. Во время записи/undo действия и Back
заблокированы, чтобы повторный тап не отправил второй запрос.

API возвращает удалённое событие, а не состояние матча: ответ создания должен
сохранять id/sequenceNumber для проверки отмены. Перед undo проверяется хвост
журнала. Undo не повторяется автоматически; после неоднозначного результата
читается журнал, при невозможности подтвердить исход блокируются дальнейшие
записи и предлагается только повторная проверка (GET). Чужие изменения не
применяются к локальному snapshot вслепую. Полная реконструкция матча после
повторного входа, redo, автоматический выбор пуллера и изменения backend вне
этой задачи. API не поддерживает атомарный expectedEventId.

Выбран одиночный snapshot с идентичностью последнего события; существующая
незамерженная реализация с историей состояний не соответствует одношаговой
семантике и используется лишь как справочный материал для API.
